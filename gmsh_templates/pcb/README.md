# PCBベンチマークのGmshテンプレート

設定書: [pcb_problem_benchmark_settings.md](../../pcb_problem_benchmark_settings.md)（5章・6章・15章）

| テンプレート | 問題 | カーネル・分割 |
|---|---|---|
| `p01_microstrip.geo` | P01 一様マイクロストリップ（5.5節） | OpenCASCADE、Delaunay＋Netgen最適化 |
| `p02_thin_microstrip.geo` | P02 薄層マイクロストリップ（5.6節） | 組込み、基板は押し出し（Layers）、空気はDelaunay |
| `p03_signal_via.geo` | P03 多層信号ビア（15.3節） | OpenCASCADE、HXT |
| `p04_multilayer.geo` | P04 誘電率ジャンプ多層基板（5.8節） | 組込み、基板は層ごとに押し出し（Layers）、空気はDelaunay |
| `p05_plane_pair.geo` | P05 電源・グランドプレーン対（15.3節） | 組込み、押し出し（Layers） |
| `p06_slot.geo` | P06 基準プレーンスロット（5.10節） | OpenCASCADE、Delaunay＋Netgen最適化 |
| `p07_diff_via.geo` | P07 差動ビア・4ポート（5.11節） | OpenCASCADE、HXT |
| `p08_multiline.geo` | P08 多ポート配線網（5.12節） | OpenCASCADE、Delaunay＋Netgen最適化 |

- 長さ単位はmm。周波数はGHz（`freqGHz`）で与え、\(\lambda_0=299.792458/f\) [mm] から要素寸法を決める。
- パラメータセットは `freefem/pcb/pcb_case_parameters.json`。既存の `gmsh_templates/case_parameters.json` と同じ構造（`template`、`parameter_sets`）に、次を加えた。
  - `physical_groups`: 期待する物理グループ。`surfaces_optional` はパラメータによってはないもの（帰路ビア0本のP03-3の `PEC_ReturnVia`）
  - `ports`: ポートの中心・幅・高さ（パラメータ名の式）、高さ方向（グランドから配線へ）、基準抵抗。`run_pcb_benchmark.py run` がE1代用電流源の配置に使う
- テンプレートの `名前 = 値;` の行が、パラメータセットの同名の値で置き換えられる（`../inject_params.py` と同じ規則）。JSON中の `description`、`role`、`mesh_level`、`tanDelta` などテンプレートにない名前は無視される。
- サイズ場は不連続にしない（基板と空気の境界で寸法が跳ぶとスリバーができる）。基板の寸法はBox場で成長率に合わせて空気の寸法へ移す。

## 形状

### P01

- 基板 \([-20,20]\times[-20,20]\times[0,1.6]\)、空気は側方に `airSide`＝5 mm、上に `airH`＝20 mm。
- 配線は \(z=h\) のゼロ厚面、\(|x|\le w/2\)、\(y\) 方向に基板全長。
- ポート1は \(y=-L/2\)、ポート2は \(y=+L/2\) の \(|x|\le w/2,\ 0\le z\le h\)。高さ方向は \(+z\)。
- 外部境界のうちグランドとポート以外はすべて `OuterBoundary`。空気余白の底面（\(z=0\)、基板の外側）も `OuterBoundary`。
- 有限厚配線（段階2、作業K）: `tTrace` \(>0\) で、配線を \([-w/2,w/2]\times[-L/2,L/2]\times[h,h+t]\) の直方体としてメッシュから除き、その表面を `PEC_Trace`（外面）にする。配線の稜線から \(t\) 以内は `edgeFactor`\(\times t\)（既定2、0.07 mm）、外へ成長率1.3。`tTrace = 0`（既定）では従来のメッシュと同一（MD5一致を確認）。

### P01の段階5（ソルダーレジスト）

- P02のテンプレートで作る（薄い層を押し出しで扱えるため）。`tRes` \(>0\) で、基板の上の \(|x|\le w/2+\) `resMargin`（既定1.6 mm）・全長に厚さ `tRes` の誘電体層（`Substrate2`、`nRes`＝1要素層）を置き、ゼロ厚配線を覆う。底面は \(x=\pm(w/2+\)`resMargin`\()\) でも分ける。空気箱のタグは `tRes` \(>0\) のとき1000ずらす（押し出しの自動タグとの衝突を避けるため）。`tRes = 0`（既定）ではP02のメッシュは従来と同一（MD5一致を確認）。
- セットは問題P02の `P02-sr_h1.6`（\(h=1.6\)、\(w=3.07\)、1 GHz、レジスト20 µm・\(\varepsilon_r=3.5\)）と、レジストなしの参照 `P02-sr0_h1.6`。

### P02

- P01と同じ配置・ラベル・ポート・パラメータ名（基板 \([-20,20]^2\times[0,h]\)、ゼロ厚配線 \(z=h\)、空気は側方5 mm・上20 mm）。\(h=0.8,\ 0.2,\ 0.05\) mm。P02-aは \(w=3.07\) 固定、P02-bは \(w/h\approx1.92\)（1.54、0.38、0.096 mm）。10 GHz。
- 基板は底面の三角形分割を厚さ方向に `nH`＝3層押し出す（各プリズムを四面体3つに分割）。底面は \(x=\pm w/2\) の線で3面に分け、中央の面の上面が `PEC_Trace`、端面（\(y=\pm L/2\)）がポート。空気は基板の面メッシュからDelaunayで埋める（組込みカーネル。空気の底面 \(z=0\) は基板の足跡を穴にした面）。
- 面内寸法は配線から \(h\) 以内で \(w/n_W\)（\(n_W=4\)、\(\lambda\) 規則の \(\lambda_0/(10\sqrt{\varepsilon_r})\) 以下）、外へ成長率1.3で基板の \(\lambda\) 規則の寸法まで、空気は \(\lambda_0/10\) まで（Box場、P01と同じ）。
- テンプレートの選択（作業J-1a）: P01のテンプレート（等方的なDelaunay、配線付近 \(\min(w/4,h/3)\)）で \(h\) だけ変えると、P02-b \(h=0.8\) は辺13.1万・最小二面角12.8°（押し出しでは10.8万・8.9°）、P02-b \(h=0.2\) は辺44.4万・7.3°（同35.6万・2.5°）、P02-a \(h=0.2\) は \(h/3\) の寸法が配線全面（3.07×40 mm）に及び、5分以上で生成が終わらなかった。\(h=0.05\) はさらに大きい。P02の目的（最小・最大要素寸法比への耐性、要素品質と反復回数の関係）に合わせ、全セットを押し出しの同じテンプレートで作る。扁平な四面体（P02-a \(h=0.05\) で最大アスペクト比45、最小二面角0.6°）は意図したもの。
- 同じ入力から同じメッシュ（MD5一致）を確認した。

### P04

- P01・P02と同じ配置・面ラベル・ポート（伝搬方向 \(y\)）。基板 \([-20,20]^2\times[0,1.6]\) は厚さ `tLayer`＝0.4 mmの4層で、下から \(\varepsilon_1,\varepsilon_2,\varepsilon_1,\varepsilon_2\)。第1・3層が `Substrate`（`epsSub`・`tanDelta`）、第2・4層が `Substrate2`（`epsSub2`・`tanDelta2`）。
- 配線は \(z=1.6\) のゼロ厚面、幅 \(w=1\) mm、基板全長。ポートは \(y=\mp L/2\) の \(|x|\le w/2,\ 0\le z\le1.6\)（4層を貫く内部面、高さ方向 \(+z\)）。JSONの `ports` の高さは `4*tLayer`。
- 基板はP02と同じく底面（\(x=\pm w/2\) で3面に分割）の三角形分割を押し出すが、材料の層ごとに4回押し出す（1層あたり `nH`＝1要素層）。材料界面はメッシュの面になり、4層とも面内の分割は同じ。
- 面内寸法は誘電率の大きい方の層の \(\lambda\) 規則 \(\lambda_0/(10\sqrt{\max(\varepsilon_1,\varepsilon_2)})\)（5 GHz、\(\varepsilon_r=100\) で0.6 mm）、配線から \(4\,t_{\mathrm{Layer}}=1.6\) mm以内は \(w/4=0.25\) mm、外へ成長率1.3。厚さ方向0.4 mmは \(\varepsilon_r=100\) の規則（0.6 mm）を満たす。
- `meshEps`（既定0）を正にすると、寸法の規則にその誘電率を使う。`P04-1_m100`〜`P04-3_m100`（診断）は \(\varepsilon_2=1,\ 4.4,\ 10\) を \(\varepsilon_2=100\) のメッシュ（P04-4とMD5一致）で解くためのセット（コントラストの効果とメッシュの違いを分ける）。
- 辺の数は配線まわりの細分化（空気側を含む）で決まり、\(\varepsilon_2=1\sim10\) ではほぼ同じ（33万〜34万。空気が四面体の約6割）。\(\varepsilon_2=100\) は基板全面が0.6 mmになり49万。
- 同じ入力から同じメッシュ（MD5一致）を確認した。

### P03

- 基板 \([-10,10]^2\)、L4 \(z=0\) / L3 \(z=0.6\) / L2 \(z=1.2\) / L1 \(z=1.4\)。空気は上下・側方に5 mm。
- L1マイクロストリップ（幅0.38）は \(x=-10\) から原点のランドまで、L3ストリップライン（幅0.55）は原点のランドから \(x=+10\) まで。ランド径0.6はL1とL3のみ。
- L2・L4は全面プレーンで、原点にアンチパッド（径0.9）。L4は基板下面（下は空気）。
- 信号ビア（径0.3）は、貫通（`backdrill = 0`）で \(z=0\sim1.4\)、バックドリル（`backdrill = 1`）で \(z=0.6\sim1.4\)。帰路ビア（径0.3）はL4–L2間、中心距離1.0で45°から等間隔。
- ポート1は \(x=-10\) の \(|y|\le0.19,\ 1.2\le z\le1.4\)（高さ方向 \(+z\)）、ポート2は \(x=+10\) の \(|y|\le0.275,\ 0.6\le z\le1.2\)（高さ方向 \(-z\)）。
- Netgen最適化はGmsh 4.15.2でこの形状に対してセグメンテーション違反を起こすので使わない。既定のDelaunayでは最小 \(\gamma\approx0.03\sim0.06\) のスリバーが残ったので、HXT（最小 \(\gamma\ge0.16\)）にした。同じ入力から同じメッシュ（MD5一致）を確認した。
- 診断用のパラメータ（引継ぎメモ作業F。既定値では既存セットのメッシュは変わらない）:
  - `meshFreqGHz`: メッシュ寸法の規則に使う周波数。0（既定）なら `freqGHz`。周波数だけを変えて同じメッシュで解くときに使う（`P03-1_1GHz`）
  - `meshAlgo3D`: `Mesh.Algorithm3D`（既定10＝HXT）。P03-1での比較: HXT 最小二面角6.1°、Delaunay（1）2.5°、R-tree（9）1.2°、MMG3D（7）はサイズ場の設定で失敗、Frontal（4）は10分以上かかり実用外
- P03-1の二面角10°未満の四面体（22個）は、すべて基板側面のすぐ外側の空気にある（薄層の面内寸法から空気の寸法へ移る所）。`aspectMax` を2にすると0個になる（辺は約20%増）。

### P05

- 領域は誘電体 \([0,100]\times[0,95]\times[0,0.4]\) のみ。下面 `PEC_Ground`、上面 `PEC_Power`、側面 `PMC_Edge`。
- ポート1は \(y=10\) の \(9.8\le x\le10.2,\ 0\le z\le0.4\)（高さ方向 \(+z\)）。
- 下面を \(y=10\) の線で2面に分け、その線のポート区間を押し出してポート面にする。\(y=10\) の他の区間は名前のない内部面。
- 面内2.5 mm、給電点から0.4 mm以内は0.2 mm、成長率1.3。厚さ方向2層（`nLayers`）。
- 体積導体（作業N、P01段階4の検証）: `tCond` \(>0\) で、両プレーンを厚さ `tCond` の金属板（体積 `Conductor`、タグ9、\(z\in[-t,0]\) と \([g,g+t]\)）にする。同じ面内分割から押し出し、誘電体側の第1層が `condH1` 以下（表皮深さの1/2）、そこから比 `condGrowth` で厚くなる層（層数は自動）。`PEC_Ground`・`PEC_Power` は金属板の外面になり、誘電体と金属の界面は名前のない内部面。`tCond = 0`（既定）では従来のメッシュと同一（P05-2でMD5一致を確認）。
- 平行平板線路（作業N）: `portFull = 1` で給電の分割をやめ、誘電体の端面 \(y=0\) 全体をポート（外面）にする（`feedX = planeX/2`、`feedY = 0`、`portW = planeX` を合わせて指定）。他端と側面はPMCで、全幅給電の開放端線路になる。`portFull = 0`（既定）では従来のメッシュと同一（MD5一致）。

### P06

- 基板 \([-30,30]^2\times[0,0.8]\)（FR-4、\(\tan\delta=0.02\)）。空気は側方5 mm、上20 mm（`airH`）、下20 mm（`airBelow`）。配線（幅1.54 mm）は \(z=h\)、\(y\) 方向に基板全長。ポートは \(y=\mp L/2\)（P01と同じ）。
- グランドは \(z=0\) の基板下面で、下にも空気があるので内部面（`PEC_Ground`）。スロットの開口 \(|x|\le L_s/2,\ |y|\le w_s/2\)（`slotL`、`slotW`＝1 mm）は `PEC_Ground` から除いた名前のない内部面（条件を課さない）。`slotL = 0` でスロットなし。
- 理想ステッチング（`stitchD` \(>0\)）: \(x=\pm d_s\) に幅 `stitchW`＝1 mmのPEC帯。独立のラベルは作らず `PEC_Ground` の一部にする（開口が3つに分かれる）。配線が跨ぐ開口は中央の長さ \(2d_s-1\) mmの部分。
- メッシュはP01の規則（配線・ポートから \(h\) 以内 \(\min(w/4,h/3)\)）に、スロット開口から \(h\) 以内 \(w_s/4\)（`nSlot`＝4）を加えたもの。寸法の規則は全セット10 GHz（`meshFreqGHz`。解く周波数は `freqGHz` または `run --freq`）。

### P07

- P03の4層基板（\([-10,10]^2\)、L4 \(z=0\) / L3 \(0.6\) / L2 \(1.2\) / L1 \(1.4\)）に差動対。線路Pは \(y=+p/2\)、線路Nは \(y=-p/2\)（`pitch` \(p=1.0\)）。
- 信号ビア（径0.3、ランド0.6、各ビアにアンチパッド径0.8）はP \((0,+p/2)\)、N \((\Delta,-p/2)\)。`viaShift` \(\Delta\) は非対称性（Nのビアを \(x\) 方向にずらす。NのL1配線が \(\Delta\) 長く、L3配線が \(\Delta\) 短くなる）。貫通ビア（スタブL3–L4、`backdrill = 0`）。
- 帰路ビア（L4–L2、径0.3）は2本: \((0,\pm(p/2+1.0))\)（対の外側）。`nReturnVias = 4` でさらに \((-1.0,\pm p/2)\)。
- ポート: `Port1`・`Port2` はL1の線路P・Nの端（\(x=-10\)、\(z=1.2\sim1.4\)、高さ方向 \(+z\)）、`Port3`・`Port4` はL3の線路P・Nの端（\(x=+10\)、\(z=0.6\sim1.2\)、高さ方向 \(-z\)）。差動ポートは (1,2) と (3,4)（JSONの `differential_pairs`）。
- メッシュ規則・分割法（HXT）はP03と同じ。1 GHzのセットも10 GHzのメッシュ（`meshFreqGHz`）。

### P08

- P01の断面（\(h=1.6\)、\(w=3.07\)）の平行配線 \(N\) 本（`nLines`）。配線 \(k=1,\dots,N\) の中心は \(x_k=(k-(N+1)/2)(w+s)\)、\(s\) は配線の縁どうしの間隔。基板幅は \(N(w+s)+20\) mm、長さ40 mm。
- ポートは配線 \(k\) の近端（\(y=-L/2\)）が `Port(2k-1)`、遠端（\(y=+L/2\)）が `Port(2k)`（タグ21〜36）。JSONの `lines` に（近端、遠端）の対を置く（`assemble_s_matrix.py` のクロストーク）。
- ポートの数が \(N\) で変わるので、JSONの問題は \(N\) ごとに分ける: `P08-N2`、`P08-N4`、`P08-N8`（テンプレートは共通）。セットは `P08-N<N>_s1`（\(s=w\)）、`_s2`（\(s=2w\)）。
- メッシュはP01の規則、寸法の規則は10 GHz（`meshFreqGHz`）。

## メッシュの生成と確認

```
pip install gmsh                                             # Python API（Linuxでは libGLU も必要）
python3 gmsh_templates/pcb/generate_pcb_meshes.py --list     # パラメータセット一覧
python3 gmsh_templates/pcb/generate_pcb_meshes.py            # 全セット
python3 gmsh_templates/pcb/generate_pcb_meshes.py --problems P03 --check-only
```

- 出力: `generated_meshes/pcb/geo/<set>.geo`、`generated_meshes/pcb/mesh/<set>.msh`（MSH 2.2）、`generated_meshes/pcb/mesh_report.json`。
- 検査項目:
  - 物理グループの有無・タグ・要素数
  - 各面ラベルの三角形が四面体の面になっているか（外面は1個、内部面は2個の四面体に接する。どの四面体にも属さない三角形は誤り）
- 記録項目: 節点数、辺数（Nédélec 1次の自由度の上限）、四面体数、境界三角形数、最小・平均・最大辺長、最大アスペクト比（\(1/\gamma\)）、最小・最大二面角、二面角が5°・10°未満の四面体数（`tets_dihedral_below_deg`）、最小SICN、生成時間、ファイル容量。
- `--out` はリポジトリの外でもよい（報告の `geo`・`msh` は絶対パスになる）。
- セットごとにGmshを初期化し直す（`gmsh.clear()` はオプションを消さないので、P03・P07のテンプレートが設定するHXTなどが、同じ実行で後に生成するセットに残らないようにする）。メッシュは一緒に生成するセットの選び方によらない。
- 検査に失敗すると終了コード1。
